# Data Analytics Project

## Overview

This project demonstrates an end-to-end **Data Analytics workflow** involving data loading, exploratory data analysis (EDA), data cleaning, SQL-based querying, and dashboard creation using Power BI.

The goal of this project is to extract meaningful insights from raw data and present them through interactive visualizations.

## Project Steps

### 1. Data Loading

* Imported dataset into Python using Pandas
* Checked dataset structure, columns, and data types

### 2. Exploratory Data Analysis (EDA)

* Performed statistical summary analysis
* Identified trends, patterns, and distributions
* Created visualizations for better understanding

### 3. Data Cleaning

* Handled missing values
* Removed duplicates
* Corrected data formatting issues
* Standardized column values

### 4. SQL Analysis (PostgreSQL)

* Loaded cleaned data into PostgreSQL server
* Executed SQL queries for:

  * Filtering and sorting data
  * Aggregations and grouping
  * Joins and analytical queries
  * Business insight extraction

### 5. Power BI Dashboard

* Connected processed data to Power BI
* Built interactive dashboards and reports
* Created KPIs, charts, and filters for visualization

## How to Run

### Prerequisites

Install required Python libraries:

```bash
pip install pandas matplotlib seaborn psycopg2
```

### Steps

1. Clone the repository:

```bash
git clone <repository-link>
```

2. Open the Jupyter Notebook.

3. Run the Python scripts/notebooks for:

   * Data loading
   * EDA
   * Data cleaning

4. Connect PostgreSQL server and execute SQL queries.

5. Open the Power BI file (`.pbix`) to view the dashboard.
